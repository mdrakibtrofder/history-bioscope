# History Bioscope · ইতিহাস বায়োস্কোপ

An interactive historical timeline & geo-visualization platform for **Bangladesh**, **Islamic** and **World** history, built with a blue & white museum-style theme.

## Quick start

Requirements: **Node.js 20+** (Node 22 recommended).

```bash
npm run setup     # installs root, backend and frontend packages (first time only)
npm run dev       # starts the API (port 4000) and the website (port 3000)
```

Open **http://localhost:3000**

- API: http://localhost:4000/api
- Swagger docs: http://localhost:4000/api/docs

Only want the website? `npm run dev:web` works too. Without the API the site switches automatically to **browser storage mode** (bundled data plus edits saved in your browser).

Production build: `npm run build` then `npm start`.

## What's inside

| Feature | Where |
|---|---|
| 236 events across 21 eras (Bangladesh 75 · Islamic 86, including all 25 prophets · World 75) | `data/seed/events.json` |
| 5 timeline modes: Horizontal (zoom/drag), Story (vertical), Century, Event cards, Journey (documentary autoplay with narration) | `/timeline/bangladesh` … `/timeline/all` |
| Map explorer: Political / Satellite / Terrain / Historical base maps, event markers, animated trade, migration, military and journey routes, empire territories with a time-travel slider, Google Maps / Google Earth links | `/map` |
| Event pages: story, significance, Wikipedia photo gallery, videos, documents, references, locations, related events | `/events/[id]` |
| Knowledge graph (React Flow + d3-force): people, places, empires, battles, religions, events with filters | `/graph` |
| Global search (Ctrl/⌘ + K) plus advanced filters (time range, region, civilization, category) | `/search` |
| Stories / blogs (Markdown) | `/stories` |
| Admin: dashboard charts, event CRUD with draft/publish, map coordinate picker, media upload, Markdown blog editor, locations, storage settings, reset | `/admin` |

## Architecture

```
history-bioscope/
├── data/seed/            # canonical JSON seed data (generated by scripts/build-seed.mjs)
├── scripts/              # seed authoring sources (edit, then run `npm run seed`)
├── backend/              # NestJS API
│   └── src/
│       ├── storage/      # Storage abstraction layer
│       │   ├── storage.interfaces.ts   StorageProvider / MediaStorageProvider
│       │   ├── storage.factory.ts      Factory pattern (chooses engine from .env)
│       │   ├── storage.module.ts       Dependency injection tokens
│       │   ├── providers/  LocalStorageProvider (JSON file) · MongoProvider · PostgresProvider
│       │   └── media/      LocalMediaProvider · MinioProvider · CloudinaryProvider · S3Provider
│       ├── common/base.repository.ts   Repository pattern
│       └── modules/      events (TimelineRepository) · blogs (BlogRepository) · media (MediaRepository)
│                         · locations (LocationRepository) · map · graph · search · meta
└── frontend/             # Next.js 15 App Router · TypeScript · Tailwind CSS 4 · shadcn-style UI
    └── src/
        ├── lib/data/     # client DataSource abstraction: ApiDataSource | LocalStorageDataSource
        ├── lib/store.ts  # Zustand
        ├── lib/hooks.ts  # TanStack Query
        └── components/   # timeline, map (Leaflet), graph (React Flow), admin, ui
```

### Switching storage engines
Edit `backend/.env`:

```
STORAGE_DRIVER=json        # json | mongo | postgres
MEDIA_DRIVER=local         # local | minio | cloudinary | s3
```

The JSON and local-disk drivers are fully implemented. The others are ready-to-fill classes with the same interface, so services and repositories never change.

Data is stored in `backend/storage/db.json` (created from `data/seed` on first run) and uploads in `backend/uploads/`. Run `npm run reset-data` to start fresh.

## Notes
- Photos and summaries load live from Wikipedia / Wikimedia Commons, so an internet connection is needed for images and map tiles.
- **Maps need no API key.** Base maps come from free, keyless tile servers (CARTO, Esri, OpenStreetMap, OpenTopoMap, EOX Sentinel-2), and each layer automatically falls back to another keyless provider if one fails (`frontend/src/components/map/tiles.ts`). Place search uses OpenStreetMap Nominatim with Photon as a fallback, also keyless. Google Maps / Google Earth are plain outbound links, so they need no key either.
- Out of respect for Islamic tradition, prophets and Seerah events show decorative covers instead of figurative images.
- Dates for prophets and very early periods are traditional or approximate, and are labelled as such.
- The admin area has no login (it is meant for local use). Add authentication before deploying publicly.
